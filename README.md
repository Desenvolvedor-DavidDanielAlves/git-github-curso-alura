<h1>Projeto jogo do número secreto</h1>
<p>O projeto jogo do número secreto foi um desafio de lógica de programação criando meu primerio site em com Javascript 
  emplementando toda a lógica do jogo e utilizando a biblioteca de voz para que o jogo fique ainda mais dinâmico e acessivel
</p>
<h2>Funcionalidades do projeto</h2>
<ul>
  <li>Sistema simples de um jogo de adivinhação</li>
  <li>Biblioteca de leitura de texto para acessibilidade</li>
  <li>Código limpo utilizando boas práticas e lógica de programação bem estruturada</li>
</ul>
